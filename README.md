# PNS Data Pipeline
This repository contains the Python ETL pipelines for the Paws-N-Shades Data Warehouse.

## Architecture
- **Shopify**: Extracts Orders, Fulfillments, Refunds, Products, Inventory, and Locations.
- **Gorgias**: Extracts Support Tickets.
- **Google Merchant Center**: Extracts Product Diagnostics.
- **BigQuery**: Destination Data Warehouse.
